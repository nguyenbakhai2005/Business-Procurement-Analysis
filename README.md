# Procurement Spend & Performance Analysis 

**End-to-End Data Analytics Project**  
*SQL Analysis + Tableau Visualization + Business Reporting*
## 📋 Overview

This project provides a comprehensive analysis of procurement operations using **5,200 purchase orders** from 2022 to 2024. The analysis focuses on spending patterns, supplier performance, cost savings, compliance, and Procure-to-Pay efficiency.

**Business Objective:**  
Uncover actionable insights to reduce costs, minimize risks, improve supplier performance, and enhance overall procurement efficiency.

**Key Deliverables:**
- Deep SQL analysis on SQL Server
- Interactive Tableau Dashboard
- Executive Summary Report
- Professional PowerPoint Presentation

## 📊 Dataset

- **Rows:** 5,200 purchase orders
- **Columns:** 57
- **Time Period:** 2022 – 2024
- **Key Features:**
  - Purchase Order Information (PO Number, Date, Status, Type)
  - Supplier Details (Name, Country, Region, Tier, Risk, ESG Score, Preferred Status)
  - Item & Category Details
  - Financials (Unit Price, Budget, Savings Amount & %, Line Total)
  - Delivery Performance (Days Late, On-Time Delivery, Lead Time)
  - Compliance (Maverick Spend, Contract Type, Invoice Status)

## 💡 Key Insights

- **Preferred Supplier Paradox:** Non-preferred suppliers accounted for **$604M** vs **$304M** from preferred suppliers, while delivering better performance (higher savings rate 8.7% vs 8.08%, fewer days late, and better ESG scores).
- **Cost Savings:** Spot contracts drove **51.36%** of total savings, while Long-term and Framework contracts contributed significantly less.
- **Compliance & Maverick Spend:** Maverick spend represented **10.8%** ($98.18M) of total spending.
- **P2P Process Gaps:** 26.38% unmatched invoices, 15.52% overdue, and 12.56% disputed.
- **On-Time Delivery:** Overall OTIF rate is only **64.13%**.
- **Budget Control:** Most categories stayed under budget, with IT Software and Professional Services being the highest spend areas.

- **Compliance Analysis** – Maverick spend, invoice issues, and contract compliance
- **Cost Optimization** – Budget variance, savings opportunities, and recommendations

**Features:** Interactive filters, drill-down, tooltips, and dynamic visualizations.

## 🎯 Business Recommendations

- Upgrade high-performing non-preferred suppliers to Preferred status
- Renegotiate Long-term contracts with volume-based discounts
- Implement controls to reduce Maverick Spend
- Add penalty clauses in SLAs for low OTIF suppliers
- Deploy automated risk alert systems
